# 블로그 리디자인 감사

2026-09-26 기준. **감사 및 제안 문서이며 구현 승인이나 코드 변경을 뜻하지 않는다.** 범위는 공개 `apps/web`의 홈, 글 목록, 글 본문, 탐색, 푸터, 모바일, 라이트·다크 모드다. 관리자와 Inspirations의 개별 화면은 공통 토큰의 영향 범위로만 다룬다.

## 근거와 방향

- `docs/git-rules.md`를 먼저 확인하고 현재 워크트리의 컴포넌트, 전역 CSS, 콘텐츠를 읽었다. 로컬 Next.js 렌더링을 Chromium에서 1440px 데스크톱과 정확한 390px 모바일 뷰포트로 확인했다. 홈, 목록, 본문의 라이트 화면과 홈·본문의 다크 화면을 검사했다. 현재 공개 한국어 글은 한 건이고 `content/posts/2025-retrospective/ko.md`는 초안이다. 따라서 다수 게시물의 밀도와 긴 목록의 동작은 코드 기반 제안으로 남긴다.
- 참고한 공개 사이트의 **정보 구조**: [Toss Tech](https://toss.tech/?tag=simplicity)는 분야별 탐색과 제목·요약·작성자를 앞세우고, [LY Tech Blog](https://techblog.lycorp.co.jp/ja)는 최신 글과 기술 주제를 구분하며, [Cloudflare Blog](https://blog.cloudflare.com/)는 주제 탐색과 날짜·제목·요약·작성자를 반복 가능한 글 단위로 제시한다. 이 원칙을 개인 블로그 규모에 맞게 적용한다. 그 사이트의 외형이나 브랜드 요소는 복제하지 않는다.
- 목표 인상: **조용한 개인 기술 간행물**. 별이 있는 밤과 눈이 오는 낮은 사이트의 배경으로 유지하고, 글을 읽는 면은 안정된 종이 또는 잉크 같은 표면으로 만든다. 현재의 개인 사진과 글의 목소리는 남긴다. 여기서 “AI 슬롭”은 제작 출처를 단정하는 말이 아니라, 콘텐츠와 관계없이 반복되는 과장된 장식 관습을 가리킨다.

## AI 슬롭 패턴 감사

1. **장식의 계층 중복.** 하늘 그라디언트 위에 반투명 전역 프레임, 다시 그라디언트 카드, 테두리와 그림자가 겹친다. 라이트 목록 스크린샷에서는 게시물 한 건보다 두 겹의 큰 빈 사각형이 먼저 보인다. `globals.css:33-42`, `:211-219`, `:998-1007`, `:1042-1050`. 우선 전역 프레임과 기본 카드 그림자를 없앤다.
2. **콘텐츠와 무관한 움직임.** 배경의 두 별 레이어가 계속 이동하고 유성 여섯 개가 반복된다. 카드도 호버 시 8px 떠오른다. `site-shell.tsx:18-26`, `globals.css:247-250`, `:292-350`, `:1087-1100`. 별은 정체성으로 남기되 유성의 반복과 떠오르는 카드는 제거한다.
3. **큰 둥근 사진/타일과 획일적 카드.** 홈 프로필은 원형 사진, 글은 썸네일과 칩을 가진 동일한 패널로 표시된다. 개인성 자체는 좋지만 작은 화면에서 사진·장식이 제목 공간을 빼앗는다. `[locale]/page.tsx:64`, `post-card.tsx:27-55`, `globals.css:1131-1146`. 사진은 소개의 보조 요소로, 글 이미지는 콘텐츠와 직접 관련이 있을 때만 쓴다.
4. **모든 레이블의 ‘마이크로 브랜딩’.** `letter-spacing: .08em`과 대문자 변환이 브랜드 부제, 메뉴, 날짜, 상태, 태그에 함께 적용된다. `globals.css:469-519`. 스크린샷에서 메타가 활자 계층을 형성하기보다 장식처럼 보인다. 브랜드 부제만 제한적으로 남긴다.
5. **기능보다 장면이 큰 첫 화면.** 데스크톱 홈은 소개와 최신 글 외에 후속 독서 동선이 없고, 900px 높이 화면의 하반부가 비어 있다. `[locale]/page.tsx:45-106`. 게시물이 적은 상태를 존중하면서도 글 목록으로 가는 분명한 링크와 간결한 최신 글 목록을 둔다.

## 우선순위와 구현 단계 — 승인 후에만 착수

1. **P0 · 읽기 기반과 모바일 목록.** 단색 역할 토큰·본문 서체·읽기 폭을 확정하고 전역/카드 이중 프레임을 없앤다. 목록 `h1`과 소개를 표시하고 390px 제목 폭을 회복한다. 완료 기준: 홈/목록/본문의 라이트·다크 1440/390px에서 제목이 자연스럽게 줄바꿈되고, 글 본문은 지정된 읽기 폭을 유지하며, 가로 스크롤이 없다.
2. **P1 · 편집 구조.** 홈의 글 진입 동선, 글 목록의 행 구조, 본문 헤더/미디어/댓글 구분을 정리한다. 실제 콘텐츠가 없는 범주나 가짜 추천은 만들지 않는다. 완료 기준: 첫 화면에서 글 목록 또는 최신 글로 이동할 수 있고, 본문 제목·요약·메타·텍스트가 일관된 순서로 읽힌다.
3. **P1 · 탐색과 마감.** 모바일 브랜드/메뉴, 현재 위치 표시, 작은 푸터, `/en`의 문서 언어와 한국어 메뉴 문구를 정리한다. 완료 기준: 키보드와 터치로 주요 경로·언어·테마를 발견하고 사용할 수 있다.
4. **P2 · 분위기와 접근성.** 별/눈의 밀도·움직임을 조절하고 반복 유성을 제거한다. `prefers-reduced-motion`, 라이트·다크 대비, 포커스와 코드 블록을 검증한다. 완료 기준: 움직임 축소 설정에서는 모든 장식/스크롤 동작이 멈추고, 두 테마에서 텍스트·링크·코드·상태의 대비가 검증된다.

현재 단계의 산출물은 이 감사 문서다. **코드 수정, 배포, 디자인 적용은 하지 않았다.**
